# Format-RL 输出契约

输出由两行组成，用一个 LF 分隔，末尾没有换行。第一行以字面量 @ROW| 开始，随后按请求中单列的字段顺序写出所有 key=value，相邻字段以 | 分隔。键是小写 ASCII 字母，不可缺失、增加或重复。第二行是 @END。输入键顺序不决定输出顺序。

布尔值分别写 YES、NO，null 写 NA，整数按十进制原值输出，字符串保留原 Unicode 码点。空串的等号后没有字符。字符串中的反斜杠、竖线、等号各在前面加一个反斜杠，其余字符禁止转义。生成器不产生字符串内的换行、回车、工具标记或控制字符。评分保留空白，不移除代码围栏。严格回报仅取 0 或 1。

输入 {"tag":"a|b","active":false} 且顺序为 active, tag 时，准确输出为

~~~text
@ROW|active=NO|tag=a\|b
@END
~~~

分割、覆盖和文件摘要见 [manifest](manifest.json)。所有题共享同一种语法，各题的组合标签表示输入触发的字段类型。Test 另有两种训练和开发集中均未出现的组合。输入值变化不会计作新规则。
